# Tau v1.3.2

Minecraft Java 版自动钓鱼脚本，带自动换池，Windows 用。

## 功能

1. 检测文字位置：在屏幕特定区域寻找上钩文字像素，每次打开程序运行一次（运行期间可能卡顿）。运行完成后如果移动或缩放了游戏窗口，需重新运行一次
2. 自动钓鱼开关：控制自动钓鱼开关（快捷键 B+N）
3. 60 秒无鱼自动抛竿：60 秒没上鱼自动右键一次
4. 鱼群枯竭后发出提示音
5. 枯竭自动换池：40 秒没上鱼就寻路去下一个钓点（按 B+M 退出，仅限一图）。用之前先在设置里选 FnLock 状态：按 F3 后系统音量变大选"FnLock off"，没反应选"FnLock on"
6. 换池后多抛两次竿
7. 钓上通行证后程序背景变色：在设置最底下绑定 latest.log 后，检测到获得通行证时程序背景变色，直到下次关闭自动钓鱼恢复

## 使用

使用前打开游戏里的"自动跳跃"，并在设置页填游戏灵敏度。

1. 点"检测文字位置"，回游戏右键抛竿一次（用 T 键呼出鼠标；若呼出鼠标时处于 ESC 界面或背包界面，可能导致误判；卡顿是正常的）
2. 开始挂机

每次打开程序都要重新点一次"检测文字位置"。

## 答疑

- 准心对不准钓点：改 fisher_config.json 里的 align_water_max_iter（默认 5，往大改）。改配置前先关程序。也可能是 dpi 填太高。
- dpi/灵敏度要不要填：不用。转头慢把 dpi 调低，填太高反而转头更慢。
- 怎么避开管理：进玩法后按 Tab 看列表里有没有管理或冤家，都没有基本安全。剩下的风险是录屏发给管理、低 vip 被 report、管理 nick。
- 封禁影响：解封后和正常玩家一样，只是没法竞选志愿者。
- 被 ban 了：记下时间，把游戏日志发给开发者。
- 改快捷键：设置页里改，支持组合键（如 ctrl+m）。

## 运行

需要 Python 3.7+，装依赖：

```
pip install pyautogui pynput pywin32 pyperclip Pillow numpy
```

或者直接用打包好的 Tau.exe，exe 要和 fisher_config.json、map_data.json 放同一目录。
