# Tau v1.1

Minecraft Java 版自动钓鱼脚本，带自动换池，Windows 用。

by limu57

## 功能

- 检测上钩文字位置，自动收竿、重新抛竿，循环挂机
- 60 秒无鱼自动抛竿
- 鱼群枯竭后提示音
- 枯竭自动换池（40 秒没上鱼就寻路去下一个钓点，按 M 退出，仅限一图）
- 换池后多抛两次竿

## 使用

1. 游戏里开"自动跳跃"
2. 设置页填游戏灵敏度
3. 点"检测文字位置"，回游戏右键抛竿一次（检测时别按 Tab，可能误判；卡顿是正常的）
4. 点"自动钓鱼开关"（快捷键 N）开始挂机

每次打开程序都要重新点一次"检测文字位置"。

用自动换池前，先在设置里选 FnLock 状态：按 F3 后系统音量变大选"FnLock off"，没反应选"FnLock on"。

## 答疑

- 准心对不准钓点：改 fisher_config.json 里的 align_water_max_iter（默认 5，往大改）。改配置前先关程序，不然会被覆盖。
- dpi 和灵敏度要不要填：不用。转头慢就把 dpi 调低，填太高反而转头更慢。
- 封禁：解封后和正常玩家一样，只是没法竞选志愿者。
- 被 ban 了：记下时间，把游戏日志发给开发者。
- 改快捷键：设置页里改（默认 N 钓鱼、M 停止寻路）。

## 运行

需要 Python 3.7+，装依赖：

```
pip install pyautogui pynput pywin32 pyperclip Pillow numpy
```

或者直接用打包好的 Tau.exe。exe 要和 fisher_config.json、map_data.json 放同一目录。
