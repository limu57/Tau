## 📋 功能特性

- **自动钓鱼**：像素检测上钩文字，自动收竿 → 随机等待 → 重新抛竿，循环挂机
- **自动换池**：鱼群枯竭后自动寻路至下一个钓点，支持中转站路由、禁区绕行、落水上浮
- **检测区域跟随游戏窗口**：按游戏窗口坐标/大小计算准心位置，窗口化、多显示器、任意位置都能正确检测
- **双地图支持**：图1 / 图2 数据独立存放于 `map_data.json`，UI 一键切换，切换后保留已检测像素
- **输入隔离模式**：可选"窗口消息"模式，键盘/鼠标操作只作用于游戏窗口，不影响用户操作电脑
- **高度可配置**：全部行为参数存放于 `fisher_config.json`，设置页可改并即时生效

## 🖥 界面说明

**主页面**：
- `检测文字位置`：在屏幕特定区域寻找上钩文字所在像素。每次打开程序都需且仅需运行一次（运行期间可能卡顿属正常现象）
- `自动钓鱼开关`：控制自动钓鱼开关（快捷键 `N`）
- `选项`：60 秒无鱼自动抛竿 / 鱼群枯竭后发出提示音 / 枯竭自动换池 / 换池后额外抛竿
- `地图选择`：图1 / 图2

**设置页**：
- `鼠标设置`：游戏灵敏度、鼠标移动倍率、转向覆写、输入模式（global/window）
- `FnLock 状态`：选择当前键盘 FnLock 状态（按下 F3 后系统音量增加则选 "FnLock off"，无事发生则选 "FnLock on"）
- `配置设置`：检测/超时/导航/快捷键等参数，修改后立即生效

## 📖 使用教程

### 前置准备

1. 打开游戏设置中的**自动跳跃**
2. 于设置页填入**游戏灵敏度**
3. 按 **F3+P** 关闭 Minecraft 失去窗口焦点时的自动暂停
4. 确保 **F3+C** 能正常复制坐标到剪贴板；窗口标题需包含关键词（默认"布吉岛"，可在配置中修改）

### 开始挂机

1. 点击 `检测文字位置`，回到游戏**右键一次抛竿**（请勿在检测时按 Tab 键，可能导致误判）
2. 点击 `自动钓鱼开关` 或按 `N` 键，开始挂机

## ⚙️ 配置说明

- **`fisher_config.json`**：全部行为参数（超时、颜色容差、导航阈值、DPI/灵敏度等）
  - `current_map`：当前地图（map1 / map2）
  - `window_title_keyword`：游戏窗口标题关键词
  - `input_mode`：输入模式（`global` 全局注入 / `window` 窗口消息隔离）
  - 手动修改配置请先关闭程序；也可在设置页「配置设置」中修改（即时生效）
- **`map_data.json`**：地图点位数据（禁区、中转站、特殊钓点、钓点、水域候选、落水高度、中转规则）

## ⌨️ 快捷键

| 按键 | 功能 |
|---|---|
| `N` | 自动钓鱼开关（可在设置中修改） |
| `M` | 停止寻路（可在设置中修改） |

## ❓ 常见问题

**Q：为什么准心始终对不准钓点？**
A：可尝试增大 `align_water_max_iter`（设置页/配置中修改，决定对准水域的尝试次数）；也可能是 DPI 设置不合适。

**Q：鼠标 DPI / 游戏灵敏度有必要填吗？**
A：非必须。若觉得转头太慢可调低 DPI 或调整移动倍率；DPI 过高会导致转头速度异常。

**Q：封禁有什么影响？**
A：解封后与正常玩家相同，但无法竞选志愿者。请遵守服务器规则，绿色游戏。

**Q：被处理了怎么办？**
A：记录当前时间，将游戏日志反馈给开发者。

**Q：如何修改快捷键？**
A：在设置页「配置设置」中修改（失焦/回车即生效）。
